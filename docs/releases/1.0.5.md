# Shiftrail 1.0.5

L’icona dell’app usa l’immagine **The World** scelta dall’utente. Il disegno rimane interamente visibile, con il bordo giallo completo, nelle icone adattive del launcher. Il simbolo monocromatico delle notifiche resta la S di Shiftrail.

Per aggiornare, apri Shiftrail e premi **Scarica aggiornamento**, poi **Installa**. Puoi avviare il controllo anche da **Impostazioni → Aggiornamenti → Controlla aggiornamenti**. Se Android lo richiede, autorizza Shiftrail a installare l’APK e conferma l’aggiornamento.

Versione stabile, build 22. Aggiorna senza disinstallare per conservare profilo, turni, pause e impostazioni. Lo schema Room rimane alla versione 5.
